# Background photos (`assets/bg/`)

Soft, blurred photographs cross-fade behind each scene:

| File | Scene |
|---|---|
| `edison-neon.jpg` | title screen and photo gallery |
| `brick-marquee.jpg` | cake scene |
| `marquee-balloons.jpg` | final message |
| `blue-lights.jpg` | not used (kept as an alternative) |

The mapping is in `style.css` (`.pbg[data-s=...]`). Replace the files with your own images (any size,
1920 px wide is plenty) or delete them: the page then falls back to the plain dark gradient.

> The bundled images are placeholders collected from the web. **Make sure you have the right to publish
> them, or replace them with your own / public-domain images before making the repository public.**
